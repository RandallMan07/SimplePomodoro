## API-key storage and visibility

- The previous file `$XDG_CONFIG_HOME/simplepomodoro/freesound.json` used mode0600 but was not encrypted; clearing the input after Save did not delete that file. The UI must no longer make successful saving look like lost input.
- Use libsecret/Secret Service for new persistent storage. This desktop already has the libsecret tools/type library and an active GNOME Keyring service. Store only this application's scoped Freesound key. Never read or modify unrelated keyring items.
- Display **Saved in desktop keyring**, environment override, legacy file, or session-only state explicitly. Keep newly entered text masked after saving; on reopening show a saved-state placeholder rather than exposing the stored secret in the form. Secret Service is the desktop's credential mechanism; do not claim its API guarantees a particular at-rest encryption policy.
- Support an explicit **Move to keyring** action for a detected legacy JSON key. Delete the legacy file only after the keyring confirms successful storage. Retain read compatibility until migration; never silently create another plaintext file.
- If the secret store is missing, locked or unlock is canceled, offer current-session storage with an explicit state. Do not silently downgrade persistence. Clear/Remove must not allow an old legacy key to unexpectedly return. Keyring operations must not block GTK.
- Keep the environment override, API authorization scoping, no-secret URLs/sidecars/logs, and private credential handling. Add optional system libsecret/keyring prerequisites to packaging/README without introducing pip dependencies.

## Preview and save lifecycle

- **Preview** fetches the selected remote preview-format audio into a private temporary directory under `/tmp`, then plays it. No library save is required first. Keep the operation asynchronous/cancellable with selection-generation guards.
- Selection/query/filter changes and closing stop playback and invalidate pending work. Delete preview audio/sidecar/cache after workers finish or via stale-result cleanup so canceled operations do not republish orphaned files.
- **Save sound** independently persists the selected sound with attribution into the chosen library, whether or not Preview was used. A validated cache may be reused; otherwise use the existing bounded download. Preserve original download/preview-quality labeling in metadata and documentation rather than adding paragraphs to the form.
