## Product intent

- Keep the native Python/GTK4/libadwaita/GStreamer stack and system-package distribution.
- Sound customization provides separate warning, phase-change, and completion choices, with generated defaults available without downloads. The user can supply a local folder and audition sounds before assigning them. Optional countdown mode emits short cues aligned to the last three whole seconds before a phase boundary, without replaying missed cues after delays.
- Gallery browsing/downloads are explicit user actions. Show source and license details and preserve attribution alongside downloaded files. Ordinary timer operation remains offline. Avoid account/API-key setup where a usable public gallery permits anonymous access.
- Follow the installed Omarchy palette when present, with validated local color values and a usable default elsewhere. Apply colors consistently to GTK and the Cairo drawing. Do not modify desktop configuration.
- An active timer should account for elapsed time while the application is closed, and a paused timer should remain paused. Restore the full configuration and phase/round state. Use atomic local state writes and validate stored data. Do not replay historical sounds on reopen. Closing automatically saves without a prompt; Reset explicitly discards the countdown (user refinement 2026-10-31).
- Widget mode shares the timer with the main window. An arrow remains visible at the top center and expands on hover/focus into phase and time remaining, with useful controls and a route back to the full window. Always-on-top and workspace behavior depend on compositor support; test actual Hyprland behavior and document fallback behavior. Minimize must use a compositor-supported action or explain an unavailable action in the UI.

## Integration notes

The feature branches overlapped in the GTK window, README, smoke test, and stylesheet; these conflicts were reconciled during integration. The combined implementation loads layer-shell before GTK, applies the active palette to the widget, restores saved timers before countdown observation, saves successfully before disposing compact surfaces, and cancels gallery workers before closing. Integrated checks isolate XDG config, cache, data, and state directories. There is one timer and one tick loop.
