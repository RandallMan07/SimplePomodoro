# Sound library and countdown decisions

Status: implementation reviewed and coordinator checks passed; awaiting user acceptance. Branch: `hotfix-sound-library`. Implementation commit: `7304986`; close-lifecycle test correction: `6705604`.

## Scope and design

Provide a generated built-in sound pool and a local user-managed sound directory, defaulting to `$XDG_DATA_HOME/simplepomodoro/sounds` (normally `~/.local/share/simplepomodoro/sounds`). Configure warning, phase-change, completion, and countdown sounds independently in a native sound settings form. Folder selection, rescanning, individual preview, a synchronized countdown test, and stopping preview are explicit actions.

Keep sound discovery and countdown scheduling independent of GTK for controlled-clock testing. Stable built-in IDs and folder-relative file IDs allow settings to survive rescans. Missing files fall back to generated defaults. The downloader may add supported audio files and provenance sidecars to the directory and request a rescan; it must not duplicate library discovery or playback.

Optional countdown mode produces one short cue at each of the final three whole-second boundaries. It must use the timer's remaining time, avoid double cues on repeated callbacks, and discard missed cues after a delay. Pause, reset, mute, and close stop scheduled/testing playback. Custom countdown tracks are limited in playback length so the transition cue remains audible. Existing one-time heads-up and default tones remain available.
