# Header controls and summary widget decisions

Status: reviewed and coordinator checks passed; awaiting user acceptance. Branch: `hotfix-summary-widget`. Implementation commit: `1a33918`. Independent of palette and persistence branches.

## Scope and design

Add minimize and compact-widget controls alongside the close control. Native minimization is a window-system request and may be unsupported by Hyprland. On Hyprland use a recoverable collapsed arrow when hiding the main window; explain that behavior in its tooltip. Reactivating the launcher or choosing Open full window restores the main interface.

Use optional GTK4 layer-shell support for a true top-centered overlay surface visible above normal and fullscreen windows and across workspaces. This machine has the library installed. Anchor the small arrow at the top center without reserving desktop area. Expand on pointer hover or keyboard focus/click into a summary of phase, time remaining, round, and pause/resume/open controls. Collapse without flickering as the pointer moves into the expanded controls. Do not retain a large invisible input surface around the collapsed arrow.

The widget shares the main window's timer, tick loop, audio, and lifecycle. It must never start a second session. Verify surface support before hiding the main window. Missing library or unsupported compositor disables widget mode with an explanation and leaves the full window recoverable. Do not repeatedly raise a normal window or modify desktop configuration. GTK4 layer-shell is optional in packaging; confirm its required initialization/preload order.

References: [GTK4 layer-shell API](https://wmww.github.io/gtk4-layer-shell/gtk4-layer-shell-GTK4-Layer-Shell.html), [GTK minimize semantics](https://docs.gtk.org/gtk4/method.Window.minimize.html).

Run `./run.sh`, start a timer, and select the compact header control. Hover the top-centered arrow, verify the phase/time/round, pause/resume, then leave it and check it collapses. Click to pin the bar open. Use **Open full timer**, Escape, or reactivate the launcher to restore the full interface. Try the minimize button: Hyprland uses the recoverable arrow because native minimization is unavailable; other desktops receive GTK's native minimize request. Layer-shell is required for widget mode; GNOME Wayland and X11 are not supported by that library.

During later integration with persistence, save successfully before disposing the widget so a failed save cannot remove the only visible surface while keeping the main window hidden.
