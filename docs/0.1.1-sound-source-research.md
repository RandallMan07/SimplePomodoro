# Alternative sound sources and clip suitability

Research date: 2026-10-31. The user requested alternatives to Commons after an unsuitable bell download and poor countdown playback. This is research and diagnosis, not approval or implementation of a new provider.

## Reproduced playback problem

The downloaded `Szent Gellért-harang (Szeged)` recording in the user's sound library lasts 442.939 seconds (7 minutes 23 seconds), independently confirmed with ffprobe. A silent ffmpeg decode measured its opening 300 ms at approximately -47 dB mean volume. No audio was played to the speakers or changed.

Current countdown playback restarts a selected file at each of the final three seconds and stops it after 300 ms, including file loading/decoder startup time. There is no onset trimming or prepared short sample. A quiet opening therefore becomes a nearly inaudible repeated excerpt. Heads-up/transition/completion choices play once and are not stretched or repeated for the configured warning interval. Using a long field recording for these events can also start a long playback, subsequently interrupted by the next cue. This explains a plausible concrete failure with the downloaded clip; it is not a measured guarantee about every user's live playback latency.

## Alternatives

| Source | Fit and access | Integration implications |
| --- | --- | --- |
| [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds) and [UI Audio](https://kenney.nl/assets/ui-audio) | Curated interface packs, respectively 100 and 50 files, CC0; free download links | Strong candidate for a small curated default pool. Official direct ZIP download returned HTTP 403 to this environment, so automated download reliability remains unverified. Do not claim its sample quality has been auditioned. |
| [Freesound API](https://freesound.org/docs/api/overview.html) | Free account and API credential; search supports duration and other metadata filters; preview audio retrieval does not need OAuth | Best candidate for searchable short effects. API token for search/metadata, preview-format downloads; original-quality download requires OAuth2. Use per-user credentials rather than bundling a secret. Individual sound licenses apply. |
| [Mixkit alerts](https://mixkit.co/free-sound-effects/alerts/) | Dedicated notification/confirmation effects, free WAV/MP3 downloads without registration | Useful manual-import source. [Sound-effects license](https://mixkit.co/license/modal/sfxFree/) restricts standalone/source-file redistribution; do not treat it as an unrestricted bundled pack or assume an authorized automated gallery API. |
| [ZapSplat](https://www.zapsplat.com/faq/) | Account required; free basic downloads generally require credit, while upgrade changes format/download privileges | Alternative for manual acquisition, with more setup than a curated CC0 pack. |

Primary Freesound references: [authentication](https://freesound.org/docs/api/authentication.html), [search/download resources](https://freesound.org/docs/api/resources_apiv2.html), [API terms](https://freesound.org/help/tos_api/). API access terms are distinct from each audio file's license; commercial API use requires a separate agreement. Live authenticated search was not tested because no API credential was requested or supplied.

## Proposed revision, pending implementation plan

- Prefer curated interface effects for the default pool; use Freesound for optional broader search with a clear local API-key setup flow.
- Search by intended use and clip duration: short single-hit countdown cues, slightly longer transition/completion tones. Avoid returning unrestricted multi-minute bell recordings for countdown selection.
- Analyze/preview a prepared excerpt, let the user choose its onset and length, and use the same excerpt in testing and live playback. Decode/cache before the boundary so the 300 ms limit does not include arbitrary file-startup delay.
- Keep countdown scheduling in the app: align one cue with each requested whole-second boundary. A downloaded recording's own rhythm is not a timing reference.
- Preserve original downloads and licenses; store derived excerpts separately. Make one-shot heads-up and repeating countdown behavior explicit in the form.

No account creation, credentials, provider implementation, sound replacement, or feature approval resulted from this research.
