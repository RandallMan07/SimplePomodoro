# License choices

SimplePomodoro uses **MIT**, selected by the project owner. This permits commercial
use, modification, redistribution, and closed-source reuse, provided the copyright
and license notice are retained. It includes warranty and liability disclaimers.

| License | Main scope and obligations |
| --- | --- |
| MIT | Permissive. Retain copyright and license notices; modified versions may remain closed source. |
| BSD 2-Clause / 3-Clause | Similar to MIT; the 3-Clause version also prohibits using contributor names to endorse derived products without permission. |
| Apache 2.0 | Permissive with an explicit contributor patent grant and patent termination terms. Retain required notices, identify modified files, and preserve relevant NOTICE attribution if supplied. Does not grant trademark rights. |
| MPL 2.0 | File-level copyleft. When distributing covered software, make covered files and their modifications available under MPL; separate files in a larger work may use other licenses. |
| GPLv3 | Strong copyleft. Distributing a covered derivative work requires GPL licensing and corresponding source under its terms. Private modifications do not generally have to be published. |
| LGPLv3 | Mainly for libraries. Modifications to the covered library remain copyleft when distributed, while applications may use other licenses if linking/relinking conditions are met. |
| AGPLv3 | Adds a network requirement to GPL-style copyleft: users interacting remotely with a modified covered program must be offered its corresponding source. Particularly relevant to server software. |

All of these permit commercial use. Copyleft is about preserving recipient freedoms,
not prohibiting sales. A public repository without a license does not generally
grant others permission to reuse, modify, or redistribute its code.

For this desktop utility, MIT provides simple reuse terms. GPLv3 would instead be
a natural choice if keeping distributed derivatives open source were the priority.
Third-party dependencies retain their own licenses; the project license grants
only rights the project's contributors can grant. The bundled icon was generated;
see its provenance in `icon-generation.md`.
