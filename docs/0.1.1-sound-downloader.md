# Free sound downloader decisions

Status: Freesound replacement implemented and coordinator-reviewed; awaiting user functional acceptance. Branch: `hotfix-sound-downloader`. Freesound implementation: `0b71e65`. Depends on `hotfix-sound-library`; acceptance of the downloader does not implicitly approve its dependency.

## Current source and behavior

The user rejected the initial Commons results and authorized Freesound plus browser search. Freesound is now the primary provider. See [source research](0.1.1-sound-source-research.md) for the unsuitable seven-minute bell diagnosis and [refinement decisions](0.1.1-refinements.md) for the approved implementation plan.

In **Sound library & countdown… → Download sounds…**, search for short effects under CC0 or CC BY. Reminder mode accepts 0.05–3 seconds; Countdown pip mode accepts 0.05–0.30 seconds and onset analysis within 30 ms. Missing onset metadata is explained and excluded from Countdown results. Up to 15 API results are requested. Duration/onset filters reduce unsuitable results but do not guarantee how every sound will feel or correct the existing audio playback pipeline.

In-app search needs a Freesound account and application API key. Enter it locally through the collapsed **API key setup** form. A saved key lives separately in `$XDG_CONFIG_HOME/simplepomodoro/freesound.json`, atomically written with mode 0600. `FREESOUND_API_KEY` overrides the saved value and the UI indicates which source is active without prefilling secrets. Save/Clear affect the local file. Tokens go only in Freesound API authorization headers, never browser URLs, CDN requests, sidecars or repository files.

**Search in browser** opens the current encoded query and filters without an API key. Website downloading may require an account. In-app downloads retrieve OGG/MP3 preview-format files, not original-quality recordings; the form labels that distinction. Preserve the Freesound ID, creator, source, license, download type and actual downloaded byte count in a JSON attribution sidecar. Requests remain explicit, cancellable and bounded to 15 MiB, with no-overwrite publication and local-library refresh.

References: [Freesound resources](https://freesound.org/docs/api/resources_apiv2.html), [authentication](https://freesound.org/docs/api/authentication.html), [API overview and preview downloads](https://freesound.org/docs/api/overview.html).

## Review and manual acceptance

Agent and coordinator focused checks passed: eight provider/credential/filter/download tests plus the existing desktop GTK smoke using mocked requests, temporary credentials and browser URL assertions. Real authenticated requests and audible playback were deliberately left for the user's testing. Screenshot: [Freesound form](screenshots/0.1.1-freesound.png).

Close any other SimplePomodoro instance and run `./run.sh` from `../SimplePomodoro-worktrees/hotfix-sound-downloader`. Try **Search in browser** without a key, then use **API key setup**, save a local application key and search `beep`. Download/play a short preview and assign it in the sound form. Try Reminder and Countdown pip separately. Confirm attribution, cancellation and appropriate feedback for an invalid key or empty results.

## Initial implementation history

The original Commons implementation (`cd49ac5`) passed 45 baseline-inclusive unit tests, GTK checks, a temporary 57,361-byte CC BY-SA OGG download, and silent GStreamer decoding. That established download mechanics rather than suitability for countdowns. The user requested the source replacement after testing a much longer bell recording.
