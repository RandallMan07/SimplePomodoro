## Scope and design

Use Wikimedia Commons as the initial free gallery through its anonymous MediaWiki API. The coordinator verified a live audio search and license metadata before implementation. No API key, account, paid service, or scraper is required. References: [Imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo) and [Commons API](https://commons.wikimedia.org/wiki/Commons:API).

From the sound settings form, open a search/download dialog. Show title, creator, source, free license, duration, size, and local destination before an explicit download. Only recognized CC0/public-domain/CC BY/CC BY-SA results with supported audio and HTTPS Wikimedia download URLs qualify. Preserve attribution and source/license information in an adjacent JSON sidecar. Downloaded audio retains its original license rather than acquiring the repository's MIT license.

Run requests on background workers with timeouts, response/download limits, cancellation, and stale-callback protection. Validate redirect destinations, use safe unique filenames, publish atomically without replacing existing files, and clean up failed partial downloads. The initial maximum download size is 15 MiB. No network request occurs during ordinary timer operation. Rescan the selected sound library after download, then let the user preview/assign with existing controls.

GTK checks cover dialog lifecycle, background completion, and stale callbacks. ## Review evidence and manual check

The coordinator reviewed the network and UI code, independently ran unit and desktop GTK checks, and verified a live search returning seven supported bell matches. A 57,361-byte CC BY-SA 4.0 OGG download was written to a temporary folder with its attribution sidecar, discovered by the sound library, and decoded to end-of-stream by GStreamer using a silent sink. The temporary download was removed; no gallery audio is bundled in Git. Final suite: 45 tests pass with system GI; without GI, 42 pass and three player tests skip.
