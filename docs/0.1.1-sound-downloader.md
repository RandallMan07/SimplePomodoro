# Free sound downloader decisions

Status: Freesound and compact dialog/keyring/preview refinements implemented and coordinator-reviewed; awaiting user functional acceptance. Branch: `hotfix-sound-downloader`. Freesound: `0b71e65`; dialog/keyring/preview: `455d339`. Depends on `hotfix-sound-library`; acceptance of the downloader does not implicitly approve its dependency.

## Current source and behavior

The user rejected the initial Commons results and authorized Freesound plus browser search. Freesound is now the primary provider. See [source research](0.1.1-sound-source-research.md) for the unsuitable seven-minute bell diagnosis and [refinement decisions](0.1.1-refinements.md) for the approved implementation plan.

In **Sound library & countdown… → Download sounds…**, search for short effects under CC0 or CC BY. Reminder mode accepts 0.05–3 seconds; Countdown pip mode accepts 0.05–0.30 seconds and onset analysis within 30 ms. Missing onset metadata is explained and excluded from Countdown results. Up to 15 API results are requested. Duration/onset filters reduce unsuitable results but do not guarantee how every sound will feel or correct the existing audio playback pipeline.

In-app search needs a Freesound account and application API key. The masked API key row is now always visible. **Save key** uses the desktop keyring through libsecret; the user's typed value remains masked after saving and reopening shows saved state without loading the secret into the field. Keyring encryption/unlocking follows desktop configuration rather than custom application encryption. `FREESOUND_API_KEY` still overrides local storage and is labeled as such. If no usable keyring exists, session-only storage is explicit; new plaintext files are never created. A legacy `$XDG_CONFIG_HOME/simplepomodoro/freesound.json` remains compatible until **Move to keyring** succeeds, then it is removed. Tokens go only in Freesound API authorization headers, never browser URLs, CDN requests, sidecars or repository files.

**Search in browser** opens the current encoded query and filters without an API key. Website downloading may require an account. The **Preview** button beside the result dropdown fetches OGG/MP3 preview audio into a private temporary directory under `/tmp`, then plays it without changing the library. Selection/query/filter changes and closing stop playback and clean the cache after its writer exits. Only the centered bottom **Save sound** adds the selected sound and attribution to the library; it works independently of Preview. Preserve the Freesound ID, creator, source, license, preview download type and actual byte count in a JSON sidecar. Requests remain explicit, cancellable and bounded to 15 MiB, with no-overwrite publication and library refresh.

References: [Freesound resources](https://freesound.org/docs/api/resources_apiv2.html), [authentication](https://freesound.org/docs/api/authentication.html), [API overview and preview downloads](https://freesound.org/docs/api/overview.html).

## Review and manual acceptance

Agent and coordinator focused checks passed: eight provider/credential/filter/download tests plus desktop GTK smoke using fake keyring operations, mocked requests and temporary app data. Real authenticated requests, keyring unlock/storage and audible playback were deliberately left for the user's testing. Both dialogs measured zero vertical overflow at 900×720 and 900×800. Screenshots: [Find sounds](screenshots/0.1.1-freesound-compact.png), [library](screenshots/0.1.1-library-compact.png). See [polish decisions and evidence](0.1.1-dialog-and-widget-polish.md).

Close other SimplePomodoro instances and run `./run.sh` from `../SimplePomodoro-worktrees/hotfix-sound-downloader`. Try browser search without a key, then Save a key or migrate the legacy key into the desktop keyring. Search `beep`, select and Preview directly, then use **Save sound** only if desired. Try Reminder and Countdown pip separately. Confirm attribution, cancellation, cache cleanup and feedback for an invalid key or empty results. All routine controls should fit without scrolling on a normal viewport.

## Initial implementation history

The original Commons implementation (`cd49ac5`) passed 45 baseline-inclusive unit tests, GTK checks, a temporary 57,361-byte CC BY-SA OGG download, and silent GStreamer decoding. That established download mechanics rather than suitability for countdowns. The user requested the source replacement after testing a much longer bell recording. The previous [Commons screenshot](screenshots/0.1.1-sound-downloader.png) is historical, not the current form.
